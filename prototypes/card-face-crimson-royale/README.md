# Prototype: Crimson Royale card face

**Hypothesis:** The approved Crimson Royale Minimalist background can hold a card's name, tier, ability text and stats without losing its minimal, open look.

**How to run:** Open `card_face_mockup.html` in a browser. It needs no build step.

**Status:** In progress. The palette and background are approved. The text layout is a proposal and has not been approved.

**Findings:**
- Royal Crimson and Ruby Red text on the ivory surface pass WCAG AA (see `design/art-bible.md`).
- Champagne Gold works for the stars but is too low-contrast for text on ivory.
- Still open: artwork placement, card-family identification, and tier, Hybrid and Artifact variants.
